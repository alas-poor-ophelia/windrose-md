# Full-pane view and dockable panels

Maps don't have to live inline. Any map can open in a **full workspace tab** — from the compass ribbon icon, the **Open map in full pane** command, or a picker that lists every map in your vault. Deleting a map is also available from the full-pane picker.

In full-pane view, side panels such as the tile drawer and object drawer can **pop out into floating, dockable windows**, Photoshop-style, when you want the canvas to yourself. Panel positions persist for the session.

# Picture frame mode

**Picture frame mode** presents an embedded map as a fixed illustration rather than an editable canvas. The map header, tool palette, toolbars, and drawers are all unmounted, leaving only the map in the note. It applies to embedded maps, not to full-pane view.

Toggle it from the visibility toolbar. While the frame is active the sole remaining control is an exit button, revealed on hover — on touch devices, which have no hover state, it stays faintly visible.

The current viewport can be **locked** as the frame's default view, fixing which part of the map the frame displays.

Frame dimensions are set in settings, with separate desktop and mobile values for height and width, and per-map overrides in [Map settings]({{ site.baseurl }}/interface/#appearance). Width is optional: left unset, the frame spans the note's content column; set narrower, the frame is that width and is centered in the column. Width is capped at the column width, so a value wider than the column has no effect.
